# Ready-to-use LATIMUS files

Download the repository ZIP from GitHub using Code → Download ZIP, then extract it.

- `LATIMUS.html`: portable app. Open in desktop Chrome; create a passphrase. Export your encrypted workspace before closing.
- `LATIMUS-extension.zip`: extract, then use Chrome Extensions → Developer mode → Load unpacked and select the extracted folder.
- `LATIMUS-build.zip`: original packaged source, application and extension build.
- `SHA256SUMS.txt`: artifact integrity hashes.

Version 0.2 is an integrated alpha with three coded public-source retrieval adapters; official live endpoint verification is still blocked in the cloud runtime. See the repository README and docs/ACCEPTANCE.md for actual tested features and remaining scope. Direct file and extension loading remain unverified on desktop because the cloud browser blocks them by managed policy. Census, USAspending and Austin adapters are fixture-tested; all official live tests remain pending. Connected AI and outbound sending are unavailable. The original21-trigger scope has19 active rows and2 property-specific rows deferred by the owner for now. See docs/SOURCE_RETRIEVAL.md and docs/TRIGGER_SOURCE_ACCEPTANCE.md.
