# LATIMUS — Cross-Sector Executive Intelligence — Codex Build Pack

This pack is written for OpenAI Codex-style repository workflows.

## Installation
Copy the contents of this folder into the root of the **LATIMUS — Cross-Sector Executive Intelligence** repository.

Do not copy the other product pack into this repository.

## Start
Open the repository in Codex and use `START_PROMPT.md`.

## Important files
- `AGENTS.md` — concise durable repository instructions
- `GOALS.md` — outcomes and non-goals
- `PLANS.md` — phase roadmap
- `PROMPTS.md` — reusable Codex task prompts
- `source-spec/` — full controlling product specification
- `.agents/skills/` — focused repo-local skills
- `harness/build/` — one execution plan per phase
- `harness/roles/` — bounded specialist/subagent role playbooks
- `harness/context/` — phase discoveries/constraints
- `harness/code_review/` — independent reviews
- `harness/build-log.md` — observed verification/progress
- `REQUIREMENTS_TRACEABILITY.md` — requirement-to-evidence ledger
- `DECISIONS.md` — material decisions
